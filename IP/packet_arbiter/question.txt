# Verilog Interview Problem: Two-Input Packet Stream Arbiter

Design a synthesizable module that merges two packet streams into one output stream. **All beats of a packet must remain together; packets from different inputs must never be interleaved.**

## Interface

```systemverilog
module packet_arbiter (
    input  logic              clk,
    input  logic              rst_n,

    input  logic [1:0][7:0]    in_data,
    input  logic [1:0]         in_valid,
    input  logic [1:0]         in_last,
    output logic [1:0]         in_ready,

    output logic [7:0]        out_data,
    output logic              out_valid,
    output logic              out_last,
    input  logic              out_ready
);
```

`in_data[i]`, `in_valid[i]`, `in_last[i]`, and `in_ready[i]` belong to input stream `i`.

## Protocol

- A beat transfers on a rising clock edge when its `valid && ready` is true.
- `last=1` marks the final beat of a packet. A packet may contain just one beat.
- An input may insert gaps between beats by deasserting `valid`.
- Each input keeps `valid`, `data`, and `last` stable while `valid && !ready`.

## Requirements

- Use an **active-low synchronous reset**. Reset clears packet ownership and gives input 0 initial priority.
- When no packet is selected:
  - If only one input is valid, select it.
  - If both are valid, select the input with higher priority.
  - If neither is valid, drive `out_valid=0` and `in_ready=0`.
- Forward the selected input's `data`, `valid`, and `last` combinationally to the output.
- Drive the selected input's `ready` from `out_ready`. The other input's `ready` must be zero.
- Retain ownership until the selected packet's **last beat successfully transfers**:
  - If the selected input pauses between beats, wait for it.
  - If the output stalls, retain the selection—even if this is the packet's first beat and it has not transferred yet.
- Keep `out_valid`, `out_data`, and `out_last` stable during an output stall.
- After input `i` completes a packet, give the other input priority for the next packet. Preserve this priority through idle cycles.
- Support one beat per clock when the selected source provides continuous data and the downstream is ready, including across packet boundaries.
- No internal data buffering is required.

## Example

Both inputs have packets available after reset:

```text
Input 0: A0, A1, A2(last)
Input 1: B0, B1(last)
```

With no stalls, the output must be:

```text
A0, A1, A2(last), B0, B1(last)
```

If input 0 pauses after `A0`, input 1 must continue waiting until `A2` transfers.

## Task

Implement the module. Be prepared to explain when ownership begins and when it ends.
