Question: Unsigned Bit-Serial Restoring Divider

Design a parameterized module named unsigned_restoring_divider that calculates:

  quotient  = dividend / divisor
  remainder = dividend % divisor

Interface requirements:
1. dividend, divisor, quotient, and remainder are DATA_WIDTH-bit unsigned values.
2. Accept one set of inputs on a rising edge when start=1 and ready=1.
3. Hold busy=1 during division by a nonzero divisor, performing DATA_WIDTH bit-by-bit
   iterations in total.
4. Assert done for one clock cycle when the result is complete; quotient and
   remainder become valid together.
5. Ignore new start requests while busy=1.
6. If divisor=0: quotient=0, remainder=dividend, and div_by_zero=1.
7. Use the bit-serial restoring division algorithm, performing only one shift,
   compare, and subtract operation per cycle.

Default parameter:

  DATA_WIDTH = 8
