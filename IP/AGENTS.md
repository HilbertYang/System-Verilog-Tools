# Interview practice preferences

- When the user asks for a new Verilog/SystemVerilog interview problem, check existing problems under `IP/` to avoid unintended repetition.
- Write the problem statement in English and automatically save it as `IP/<problem_name>/question.txt` in a new descriptive directory. Do not wait for a separate request to save it, and do not overwrite an existing exercise.
- Provide the problem statement only. Do not create an implementation, golden/reference solution, or testbench unless the user asks for one.
