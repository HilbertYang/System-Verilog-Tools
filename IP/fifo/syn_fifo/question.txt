# Verilog Interview Problem: Synchronous FIFO

Design an **8-entry, 8-bit synchronous FIFO** in synthesizable Verilog.

## Interface

```verilog
module syn_fifo (
    input  wire       clk,
    input  wire       rst_n,
    input  wire       wr_en,
    input  wire       rd_en,
    input  wire [7:0] wr_data,
    output reg  [7:0] rd_data,
    output wire       full,
    output wire       empty
);
```

## Requirements

- Use an **active-low synchronous reset**. Reset empties the FIFO and sets
  `rd_data` to zero. Reset takes priority over reads and writes.
- All reads and writes occur on the rising edge of `clk`.
- An accepted write appends `wr_data` to the FIFO.
- An accepted read removes the oldest entry and updates `rd_data`.
  Otherwise, `rd_data` holds its previous value.
- A read is accepted only when `rd_en` is asserted and the FIFO is nonempty
  before the clock edge.
- A write is accepted only when `wr_en` is asserted and either the FIFO is
  not full before the clock edge or a read is accepted on the same edge.
- When both enables are asserted:
  - If empty, accept only the write; do not forward the new data to `rd_data`.
  - If full, accept both operations; the read must return the oldest stored
    entry.
  - Otherwise, accept both operations.
- `full` and `empty` must reflect the current FIFO occupancy.

## Task

Implement the module. Be prepared to explain pointer wraparound and how
simultaneous reads and writes affect occupancy.
